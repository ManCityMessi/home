两种密钥的差别
  1. 写入密钥（32 位随机串）：走 Cloudflare 写入代理，速度快。国内移动网络多半连不上这个代理，表现为「同步失败（网络）」。
  2. GitHub 细粒度令牌（github_pat_ 开头，仅授权本仓库 Contents 读写）：直接调 GitHub API，手机也能用。
手机建议用第 2 种；电脑两种都可以。
