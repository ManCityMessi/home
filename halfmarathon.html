先做这一步：把 6 个课程建进 App

  1. 手机装最新的华为运动健康（HarmonyOS 5 手机需 16.1.2.300 以上），确认手表已连接。
  2. 进入以下任一路径： 锻炼 → 跑步 → 全部跑步课 → 自定义 → 新建 旧版路径：运动 → 户外跑步 → 推荐好课旁「全部课程」 → 自定义 → 新建
  3. 点 添加动作 加单个动作，点 新增组合 做「快慢交替 + 重复 N 组」。每个动作都要设 目标（时间 / 距离）和 强度（选「配速」，填下方区间）。
  4. 右上角 ✓ 保存 → 点右上角手表图标推送到手表。
  5. 手表端：锻炼 → 课程与计划 → 跑步课程 → 自定义课程，点课程即可跟练，全程有语音播报，点屏幕可跳过当前小节。
命名规范：手表上显示字数有限，课程名别超 8 个字。用「用途-结构」格式，如 间歇-6x400、阈值-3x8分。
改量不改课：需要更多组数时，用详情页右上角「复制课程」复制一份再改组数和名字，比新建快得多。

关于「组间慢跑」的一个小坑

用「组合」做间歇时，最后一组结束后也会跟着跑一段组间慢跑。跑的时候直接在手表上点屏幕跳到冷身即可，不用真的跑完它。
