这份计划的核心取舍

30km 的周量跑 1:45（4:59/km），意味着轻松跑必须压到 20–25 分钟，把跑量全部让给质量课。这是低跑量高密度路线——每一次质量课的配速准确度，直接决定成绩。

华为运动健康没有课表文件导入通道，所以路线是：App 内建自定义跑步课程 → 推送到手表 → 锻炼 → 课程与计划 → 跑步课程 → 自定义课程 跟练。

先做这一步：把 6 个课程建进 App

  1. 手机装最新的华为运动健康（HarmonyOS 5 手机需 16.1.2.300 以上），确认手表已连接。
  2. 进入以下任一路径： 锻炼 → 跑步 → 全部跑步课 → 自定义 → 新建 旧版路径：运动 → 户外跑步 → 推荐好课旁「全部课程」 → 自定义 → 新建
  3. 点 添加动作 加单个动作，点 新增组合 做「快慢交替 + 重复 N 组」。每个动作都要设 目标（时间 / 距离）和 强度（选「配速」，填下方区间）。
  4. 右上角 ✓ 保存 → 点右上角手表图标推送到手表。
  5. 手表端：锻炼 → 课程与计划 → 跑步课程 → 自定义课程，点课程即可跟练，全程有语音播报，点屏幕可跳过当前小节。
命名规范：手表上显示字数有限，课程名别超 8 个字。用「用途-结构」格式，如 间歇-6x400、阈值-3x8分。
改量不改课：需要更多组数时，用详情页右上角「复制课程」复制一份再改组数和名字，比新建快得多。
关于付费这件事

华为「智能训练计划 / AI 跑步计划」属于「活力人生」会员权益（连续包月 15 元、月卡 20 元）。本页这套自定义课程路线完全免费，且不依赖华为的算法——配速由你自己按下方区间控制。

6 个课程模板 · 照着录入

点标题展开动作清单。每张卡片底的「复制录入文本」可以贴到备忘录里，照着填 App。

为什么热身只有 10 分钟、冷身只有 5 分钟：这是低跑量计划的刻意设计。热身和冷身占掉的距离属于「无效跑量」，30km 的周量经不起 15 分钟热身。天冷或刚起床可以自行延长 2–3 分钟。
强度怎么填：优先选「配速」，手动填上下限（例如 4:22–4:38）。不要用「配速区间」——那是华为按你的跑力自动划分的，可能跟本表不一致。

低跑量的代价，以及怎么补

长距离只到 9–11km，大约是半马的一半。这是 30km 周量下的硬性上限——后半程耐力只能靠质量课的总时长和渐进长距离来补。

如果练到 W6 之后你发现 15km 以后明显掉速，就做这个调整：把周二或周五的轻松跑改成休息，把周六长距离加到 14km。总跑量不变，只是重新分配。

关于「组间慢跑」的一个小坑

用「组合」做间歇时，最后一组结束后也会跟着跑一段组间慢跑。跑的时候直接在手表上点屏幕跳到冷身即可，不用真的跑完它。

注意事项

  • 质量课就是这份计划的全部。30km 周量下没有富余的有氧量兜底，阈值和间歇那两次课配速跑偏了，整周就白跑。
  • 轻松跑不要加量。只有 20–25 分钟，是给质量课让路的。跑爽了延长到 10km，整周结构就塌了。
  • 推送失败先查这 3 处：手表与手机蓝牙已连接、App 登录的是同一华为账号、设备页里手表处于已绑定状态。另外自定义课程同步不是所有机型都支持——如果详情页右上角没有手表图标，说明你的设备不支持，只能在 App 里点「开始训练」跟练。
  • 周量只在 28–33km 之间波动，不往上加。W4 / W8 / W12 是减量周，别跳过。漏练了也不要补，直接继续。
  • 训练日固定为周一/周二/周三/周五/周六，课程顺序是「阈值 → 轻松 → 间歇 → 轻松 → 长距离」，不要打乱。周四、周日完全休息。两次质量课之间那天的轻松跑就是恢复用的。
  • W9–W11 是专项期，那节半马配速课是最重要的训练。W9 的 11km 长距离是全周期最长的一次。
  • 最后一周的半马测试：前面 11 周练到位了再测。测完就是新的 PB 基准，可以拿它重排下一轮配速。
  • 本表是训练安排建议，不替代医疗意见。有心血管病史、关节伤病或长期不适，先问医生。
